## 🧪 Example Profile Configuration

Create a file named `marketmuse_profile.yaml` in your home directory:

```yaml
profile:
  name: "TechBlog Insights"
  industry: "B2B SaaS"
  target_audience: "CTOs and DevOps leaders"
  tone: "Authoritative but accessible"
  primary_language: "en-US"
  secondary_languages: ["de-DE", "ja-JP"]

content_strategy:
  keyword_depth: "long-tail"
  competitor_analysis: true
  semantic_expansion: 1.5  # multiplier for related topics
  output_format: "markdown"

api_integration:
  openai_model: "gpt-4-turbo"
  claude_model: "claude-3-opus-20240229"
  batch_size: 50
  temperature: 0.4

ui:
  theme: "dark"
  responsive: true
  cache_ttl: 3600  # seconds
```

Then run `marketmuse --profile marketmuse_profile.yaml` to activate this intelligence layer.

## 💻 Example Console Invocation

```bash
# Analyze a single URL for content gaps
marketmuse scan https://example.com/blog/saas-growth \
  --depth=3 \
  --competitors=5 \
  --language=en \

  --lang=ja,es,de \
  --tone=professional \
  --min-words=1500

# Batch analysis from CSV

  --strategy=clustering \
```
